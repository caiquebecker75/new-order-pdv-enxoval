# 75LAB × Grupo New Order · Enxoval de PDV

Apresentação web (deck interativo de **15 telas numeradas**) da **75 LAB** para o **Grupo New Order** (marcas **Fogatti** e **Nardelli**): estratégia, design e produção do enxoval de ponto de venda da linha de embutir.

Recursos: infográficos SVG animados, conectores e setas em looping, contadores, tabela de kits, key visuals do cliente em tela cheia sem corte, **galerias com as 16 peças de PDV** (8 por marca) e **lightbox** para ver cada peça em alta resolução e detalhe. Botão **Baixar em PDF** na capa. Imagens em `/img`.

**Peças do sistema (por marca):** Adesivo Missão de Compra · Régua Magnética · Zona Quente Adesiva · Blade Vertical · Banner Aéreo · Card QrCode · Torre de Comparação · Inspira Ambientes.
