# 75LAB × Grupo New Order · Enxoval de PDV

Apresentação web (deck interativo de **15 telas numeradas**) da **75 LAB** para o **Grupo New Order** (marcas **Fogatti** e **Nardelli**): estratégia, design e produção do enxoval de ponto de venda da linha de embutir.

Deck single-file (`index.html`): infográficos SVG animados, conectores e setas em looping, contadores, gráficos, tabelas e key visuals do cliente em tela cheia sem corte. Botão **Baixar em PDF** na capa.

**Estrutura (15 slides):** Capa → Visão geral → Mercado → Shopper → Categoria → Jornada → Arquitetura → Duas marcas → KV Fogatti → Design Fogatti → KV Nardelli → Design Nardelli → Produção/Kits → Cadeia → Fechamento.
